Flow 1 · adding a funnel

New row → Hubstaff project

When a row has Market, Code, Product Name, Date Added & Funnel Name filled in:

1

Sheet locks the row

Apps Script writes “pending” into the Hubstaff Project ID cell and calls the relay.

2

Relay creates the project

A Hubstaff project is created for the funnel, with the standard task list — each task auto-assigned to its team: EditorFunnel BuildersFacebook Launcher. General Customer Support tasks are intentionally skipped.

3

ID written back

The real Hubstaff Project ID replaces “pending” in the sheet. Runs as a background job, so it’s reliable even under rate limits.

🛡️
No duplicates

Before creating, the relay checks the sheet, its own DB, and Hubstaff by name. Same funnel → it reuses the existing project instead of making a second one.

Flow 2 · tracking the work

Assignments → Discord threads

🧵

One thread per funnel

Assign a Funnel Builder and a forum thread opens in the proofreading channel. Its ID is saved in the row’s Funnel Post Id.

🏷️

Status keeps it live

Change the row’s status and the thread is re-tagged automatically In progressFor proofreadingReady — and a comment is posted for proofreading.

🔁

Reassigning renames

Change the builder and the same thread is renamed + noted — not duplicated. Clear the builder and the thread is deleted.

🩹

Self-healing (planned)

If a thread is deleted in Discord, the next status update can recreate it automatically instead of failing silently.

For editors

Tracking time in Hubstaff

The quantity is baked into the task name — “selecting the number” just means picking the matching task, then start/stop the clock on it.

3 × 2-min videos→Video - 2min - 3 Videos
2 × 1-min videos→Video – under 1 min - 2 Videos
4 × 3-min videos→Video - 3min - 4 Videos
12 image ads→Image (from scratch) - 12 Image Ads
⏱️
Start & stop, one task at a time

Start the timer on the matching task when you begin; stop when you pause, finish, or switch task type. Count variants exist for 2/3/4-min & under-1-min videos (1–6) and images (10–20).

Rules that hold it together

Three things to know

PrincipleWhat it means
1 funnel = 1 project = 1 marketThe Funnel Name carries the market code (NLBE565 … vs DEAT565 …), so each market gets its own Hubstaff project — they never merge.
Dedup everywhereHubstaff projects matched by name; Discord threads unique per channel + title. The system reuses, never double-creates.
Dashboard keys on IDsThe KPI dashboard matches on Hubstaff project / task / user IDs pulled straight from Hubstaff — not funnel names, and not the sheet. Robust by design.
